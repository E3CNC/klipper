# E3CNC Klipper fork

E3CNC's fork of Klipper, carrying the CNC plugins (work coordinate systems, and
the feed-hold / CNC controls). Pinned to an upstream freeze tag under the
tag-and-freeze model — see `docs/adr/`.

## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues (via the `gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
